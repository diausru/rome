# A9 — Retention Blueprint (written before any visuals)

**Opening question:** you filed, then found a mistake (a late slip, a missed deduction). Do you file again?
**Promised result:** how a fix actually works, what it changes in money, and how long it takes.

**First 30 s (VO → visual):**
- 0–4 s "You filed in March. In June, a slip shows up." → frame 0: FILED IN MARCH. / THEN THIS? + a calendar card MARCH with ✓ FILED; it flips to JUNE; a late slip slides in.
- 4–9 s "File again? No." → FILE A 2ND RETURN? struck through, NO stamp; "HOW A FIX REALLY WORKS ↓".
- 9–18 s Case 1: $1,500 of union dues forgotten → a paper return page: the line is struck in red pen, $1,500 written in; +$499 back (× 33.25%).
- 19–30 s Case 2: a late T4A adds $3,000 → the income line is edited; −$998 owing + interest from May 1.

**Open questions carried:** "how far back can I go?" (case 3) and "how?" (the twist and the routes).
**Reveal (41–49 s):** a fork: ✕ FILE A SECOND RETURN vs ✓ WAIT FOR THE NOTICE, THEN CHANGE IT ("Adjust, don't refile").
**Answer + next step (49–58 s):** a comparison chart: ONLINE (Change my return, ReFILE) ≈ 2 weeks vs PAPER (T1-ADJ) ≈ 8 weeks. Bridge to H1 (Manitoba MB479 credits people miss).
